# 관문 2: 시나리오 방어 (Scenario Defense)

관문 1(백지 지도 재현 — The Assignment)이 "무엇이 어디에 있는가"를 측정한다면,
관문 2는 **"고객 앞에서 설명하고 방어할 수 있는가"**를 측정합니다. 살아있는 지도의
시나리오 렌즈·솔루션 카드·SE 심화·battlecard 계층이 시험 범위입니다.

## 시험 형식 (오프라인, 서면 또는 구두, 15분)

1. **문항 추첨**: 두 유형의 풀에서 평가자가 1개를 고릅니다 (응시자는 사전에 모름).
   - **시나리오**: 지도의 시나리오 렌즈 8개.
   - **솔루션 경계**: 솔루션 카드의 "이웃과의 경계" 쌍 — "A와 B의 경계를
     말하라." 응시자는 두 솔루션이 각각 누구의 어떤 문제를 푸는지(정의),
     공유하는 제품과 각자 전용인 제품, 그리고 고객이 어느 쪽부터 시작해야
     하는지를 답합니다. 경계 쌍은 카드의 경계 서술이 정답지이므로, 카드에
     서술이 있는 쌍만 출제합니다.
2. **상황 제시**: 평가자가 해당 시나리오의 고객 역할을 맡아 상황을 한 단락으로
   말합니다. 응시자는 도구 없이 답합니다.
3. **3단 방어**: 응시자는 다음 순서로 답합니다.
   - **조합**: 이 상황에 관여하는 Cloudflare 제품 조합과 각각의 자리(레인/레이어).
   - **근거**: 그중 두 제품에 대해 "어떻게 동작하는가"를 기술 근거(동작 원리 또는
     한계·전제 포함)로 설명.
   - **방어**: 평가자가 던지는 표준 반론 2개에 정면 대응. 표준 반론 풀:
     - "이미 (Akamai/Zscaler/AWS)를 쓰는데요."
     - "AWS에 다 있는 기능 아닌가요?"
     - "보안팀이 프록시 경유를 반대합니다."
     - "요금이 예측이 안 됩니다."

## 채점 루브릭 (각 0–3점, 총 12점)

| 축          | 0                   | 1–2                | 3                                                               |
| ----------- | ------------------- | ------------------ | --------------------------------------------------------------- |
| 조합 정확성 | 관련 제품을 못 꼽음 | 일부 + 위치 혼동   | 렌즈 구성과 실질 일치 + 위치 정확                               |
| 기술 근거   | 이름만 나열         | 용도 수준 설명     | 동작 원리·한계까지 (SE 심화 수준)                               |
| 반론 방어   | 회피하거나 얼버무림 | 부분 대응          | 이기는 곳·지는 곳을 정직하게 가르며 정면 대응 (battlecard 수준) |
| 출처 의식   | 출처 개념 없음      | "문서에 있다" 수준 | 어떤 주장이 공식 인용이고 어떤 것이 사내 지식인지 구분          |

- **1점과 2점의 눈금**: 1점 = 축의 요구를 시도했으나 절반 이하만 충족(예: 제품
  절반만 꼽음, 반론 하나만 부분 대응), 2점 = 대부분 충족하되 한 요소가 빠짐(예:
  조합은 맞으나 레이어 하나 혼동, 반론 대응은 정면이나 지는 곳 인정이 없음).
- **battlecard가 없는 제품의 방어 채점**: 해당 제품 카드의 SE 한계·전제(limits)에
  근거해 "무엇은 되고 무엇은 안 되는지"를 정직하게 가르면 3점으로 인정합니다 —
  경쟁 비교 자료의 유무가 아니라 정직한 경계 긋기가 채점 대상입니다.
- **통과선: 8/12** — 그리고 반론 방어 축이 0이면 총점과 무관하게 불통과
  (방어가 이 관문의 존재 이유이므로).
- 채점 후 놓친 축을 도구로 복기: 조합은 해당 시나리오 렌즈 또는 **솔루션
  카드(구성 제품·공유 제품이 조합 축의 정답지)**, 근거는 카드의 SE 심화,
  방어는 경쟁 비교 섹션, 경계는 솔루션 카드의 "이웃과의 경계" 서술이
  정답지입니다.
- **시험지 난이도**: 시나리오마다 제품 수(4~5)와 방어 난이도가 다릅니다. 같은
  응시자를 비교할 때는 같은 시나리오로, 서로 다른 응시자를 비교할 때는 제품 수를
  병기해 기록하세요. 평가자가 둘이면 첫 회는 같이 채점해 눈금을 맞추는 것을
  권장합니다(앵커 세션).

## 운영 노트

- 관문 1(백지 재현율 80%)을 통과한 뒤에 응시하는 것을 권장합니다 — 구조 없이
  방어는 없습니다.
- 같은 시나리오를 2주 간격으로 다시 걸면 재안개와 같은 원리의 유지 측정이 됩니다.
- 신규 시나리오가 지도에 추가되면 자동으로 시험 풀에 들어갑니다 — 시험지는
  도구의 데이터를 따라갑니다(별도 문제 은행 없음). 솔루션 경계 문항도 같은
  원리로, 카드에 경계 서술이 추가되는 순간 그 쌍이 풀에 들어갑니다.
- 솔루션 경계 문항은 도구의 회상 ③(공유 제품 문항)과 짝입니다 — 도구는
  "공유 제품"의 기억을, 서면은 방향·시작점까지의 서사를 검증합니다. 정의
  문항(②)의 자가 채점 과신은 이 서면 관문이 잡아냅니다.
